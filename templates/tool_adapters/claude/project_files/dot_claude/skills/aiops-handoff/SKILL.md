# AI Ops 인계

1. `aiops task advance TASK_ID --check` (작업을 넘길 때) 또는 `aiops task accept TASK_ID --check` (작업을 받을 때)로 준비 상태를 먼저 확인한다. 이 단계는 파일을 바꾸지 않는다.
2. 점검이 실패하면 전이하지 않고 실패한 항목과 이유를 보고한다.
3. 점검이 통과하면 같은 명령을 `--check` 없이 실행한다. 필요한 근거 파일은 `--evidence PATH`로 넘긴다.
4. 결과로 생긴 receipt와 handoff 경로를 확인한다.

## 사용자에게 설명하는 형식
- 상황: 착수 / 검증 요청 / 검증 통과 / 재작업 / 차단 / 완료 중 하나
- 무슨 일: 누가 무엇을 끝내고 누구에게 넘겼는지 한두 문장
- 바뀐 것: 주요 변경 파일이나 결과물
- 확인된 것과 남은 위험
- 다음: 다음 담당과 사용자가 할 일(없으면 "사용자 할 일 없음")

Agent에게 넘기는 기술적 인계 문구는 handoff 파일에 남기고, 사용자에게는 위 형식으로 쉽게 설명한다.
